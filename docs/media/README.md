# Media

Screen captures and stills used by R.1's documentation live here.

Nothing is checked in yet. The README marks the places a capture would earn its
keep with `<!-- CAPTURE: ... -->` comments — record one, drop the file in this
folder, and replace the comment with an image tag.

## Rules for anything added here

- **Capture R.1's own interface.** No third-party product UI, no other project's
  branding.
- **Keep in-frame attribution intact.** Captures of the globe include Google
  Photorealistic 3D Tiles and live data-provider credits; those must stay legible.
  See [DATA_SOURCES.md](../../DATA_SOURCES.md).
- **The MIT license covers source code, not media.** A capture containing
  third-party imagery or data stays subject to that provider's terms — record the
  provenance here when you add one.
- **Keep GIFs small.** Prefer short loops under ~3 MB; the repository should not
  become a video host.
